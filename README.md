mend is a command-line patch tool: it reads an AI-written edit in one of four formats (unified diff, SEARCH/REPLACE blocks, V4A, or JSON edits), finds the lines each edit names at the first of three matching tiers, and writes every change or none, printing exactly what it changed or why it failed.

## Run it

```sh
node main.ts [options] [PATCH]
```
